# 36. TECHNICAL QUALITY & PRODUCTION STANDARDS

This website must be built as a **production-quality application**, not just a visual prototype.

## Frontend

Use:

* React
* TypeScript
* Vite
* Tailwind CSS
* Semantic HTML
* SVG
* Framer Motion

Use **Framer Motion only for the hero visualization and process timeline**.

All other animations and transitions should use CSS.

Do not introduce unnecessary animation libraries.

---

## Performance Budgets

Target:

* **LCP < 2.5 seconds on mobile**
* **Total home-page JavaScript < 200–250 KB gzipped**
* Lighthouse Performance **90+ where realistically achievable**
* Optimize Core Web Vitals
* Lazy-load below-the-fold images
* Use responsive images with `srcset`
* Use properly sized images
* Optimize SVGs
* Avoid unnecessary third-party scripts
* Use code splitting where appropriate
* Avoid heavy background videos
* Minimize client-side JavaScript

Performance should be considered during implementation rather than added later.
